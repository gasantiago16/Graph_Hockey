1 What this project is (in one breath)

Graph_Hockey is a localhost Node.js hockey game where two independently compiled LangGraph.js teams compete on a deterministic 2D rink. The Match Orchestrator ticks physics at 10 Hz. Coaches only speak at decision epochs. After every win, loss, or tie, After-Action Review cites real eventIds and patches a structured playbook.

Live default AAR is --aar-mode code: a cited codeDraft in milliseconds. That is not --no-llm. Live epochs still call the coach. --no-llm never mutates — it is the control arm. The browser is a spectator. After npm run web, open http://127.0.0.1:8787/.

3 Architecture

Hard law: the browser draws frames. Scoring is geometry in src/engine/rules.ts. A hallucinated goal is JSON the validator ignores.

Green ticks never stop. Gold packets are epochs (sparse). Cyan is after the horn — the only path that may rewrite long-term memory.

10 Hz ice observe → Head Coach AAR → book

5 How the parts talk to each other

There are three clocks, not one “the agents think.” Mixing them is how you get a timeout and no hockey.

Clock 1
10 Hz

Physics + ice roles. Zero LLM. F1 may shoot. shotLock = one chance per possession.

Clock 2
Epochs

Faceoff, ST, 8s possession. One Head Coach call (6s / 12s abort). Most ticks skip this.

Clock 3
Horn

Live default --aar-mode code: milliseconds, cited apply. auto is the 45s graph. --no-llm never mutates.

The gold dot is the only LLM on a live macro. Retrieve is code. Ice still shoots if the coach is late.

1
advanceWorld — ice F1/F2/F3, steer, maybe release a pass/shot/clear, maybe whistle. Sole mutator.
2
shouldDecide — per side: macro stoppage, micro (80 live ticks), or playStillValid skip. Valid play ⇒ that side pays zero tokens.
3
observe — mirror so you attack +X. Home + away puck.x ≈ 0. No opponent playId.
4
invokeTeam — never throws. Live 12s abort (8s --no-llm). Timeout on default-structure seeds the book 5v5 play.
5
retrieve_plays — code. Ranks OUR plays by net xG + themFamily counter bonus. Empty-net families (pull-early, en-scramble) stay off unless strength is EN.
6
validateDirective — playId from retrieved list only. Illegal extra attacker rejected. Ice F1 shoot still beats overlay pass/dump.
7
AAR both sides — live default --aar-mode code applies a cited patch without the 45s graph. Boosts need match xG. --no-llm still does not mutate.
8
Film — resimulation is canonical. gh footage --mp4 is a derivative. Clip windows carry period because liveTick resets.

How the team learns together

They do not learn by stuffing the whole game into a prompt. They learn because memory is a versioned playbook that both the next retrieve and the next skate can see.

Winner: cited boost + real xG on play.stats. Loser: add_counter of their family. Next retrieve can rank a different 5v5. Proof is two diffs: did retrieveTop move vs the control, and did the hockey get better?

Together means a shared sheet. During the game they skate one play. After the horn each AAR writes into that sheet. Next faceoff, both the code retrieve and the coach see the new menu. Ten independent skater graphs would not share a sheet — they would all hunt.

7 Bugs, scars, and how we fixed them

Not hypothetical. These would have shipped a wrong hockey game.

Scar 1 — The graph that never called Head Coach

WhatepochKind lived on the observation; the router read graph state. Every epoch was micro (or Zod failed). grok-4.5 never ran.
RootConditional edges see compiled state, not your mental model of “the observation is the input.”
FixRequired top-level epochKind on invoke. Stream-visit tests for head_coach.
LessonIf a field decides a branch, put it where the framework looks.

Scar 2 — Possession without a face

WhatNearest body in stick reach got the puck while facing the wrong way. Fake stick-puck later legalized a kick-goal.
RootNearest-body tie-break ran before the 70° facing cone.
FixOnly the facing-in-reach pool. Empty pool: puck stays loose. Tests: 70° award, 70.1° deny.
LessonLast-contact kinds are load-bearing for the rulebook.

Scar 3 — Occupancy scored a kick

WhatSkate-puck into the net, then a later stick touch while the puck sat there, counted as a goal.
FixcrossedIntoNet(prev, now) plus last contact stick-puck.
LessonScore crossings, not occupancy.

Scar 4 — Empty net confused power play

WhatOn-ice counts included the extra attacker: PP goal vs PK empty net did not expire the minor; 6v5 dumps looked shorthanded for icing.
FixboxSkaterCounts vs EN overlay; restore G/F4 when the delay window closes.
LessonName the question or you mix special teams with empty net forever.

Scar 5 — Node named situation

WhatLangGraph.js refused a node name that was also a state channel.
FixWrite classifiedSituation. Also: never invent a route_specialists node — Send is not a state update.

Scar 6 — Pairing too strict to show improvement

WhatJaccard ≥ 0.7 refused Goal-against vs later Save on the same play — the film you wanted.
FixSame playId + zone first; Jaccard prefer 0.7, fallback 0.3.

Scar 7 — Graphs that never shot

Whatlive-50: 2–2, xG 0.00. Seed shoot ignored. Hunters stuffed the puck through their own net.
RootmaybeReleasePuck needed an LLM overlay. Hunt walked the crease.
Fixsrc/ice/ F1 hunt/pass/shoot/clear. Own crease is the goalie’s. Pass/clear are not Shot/xG.
LessonIf AAR needs xG, the environment must shoot without a coach.

Scar 8 — AAR timeout learned nothing

WhatLive applied: false because 45s AAR died and wrote ops: [].
FixTimeout runs codeDraft + cite. Live auto-applies. --no-llm still persist-only.
LessonEmpty-ops fallback is a silent no-op, not a fallback.

Scar 9 — Head Coach froze on default-structure

Whatlive-51: 1–0, 13 shots, all 24 epochs default-structure. Ice scored. Staff watched.
RootCoach 6s + specialist Send[] ate the 12s abort. JSON retry. Timeout returned opening last forever.
FixHC → assemble. One structured call + signal. Timeout seeds the book 5v5 play. Specialists opt-in.
LessonFan-out that cannot finish inside abort is a DoS on your own coach.

Scar 10 — 211 ok epochs, still a machine-gun

Whatlive-52: Muse 3–1, real plays, 211/212 ok — and 118 Shot rows, 166 offsides, a HOME GOAL tagged h-G.
FixshotLock one shot per possession. AAR rolls real xG into stats. Retrieve bonuses counters. Series scorecard counts chances, not Shot rows.
Lesson“The graph ran” is not hockey. Count distinct chances. Captain micro is the next 12s trap.

Scar 11 — Goals that were not chances

Whatser-learn-7: home 8 goals, 0 shots. Carry-in occupancy plus a goalie clip became Goal. Overlay pass sat on F1.
RootScoring trusted occupancy more than “there was a Shot this possession.” Overlay pass beat ice F1 shoot.
FixAttacking Goal needs a recent attacking Shot. Dump/pass/clear waveOffNetEntry. Actor is the shooter, not G. Ice F1 shoot beats overlay pass/dump.
LessonIf the label on the event is the training signal, fake labels teach fake hockey.

Scar 12 — The 45s AAR we did not need

WhatLive AAR still paid for a grok-4.5 graph that routinely timed out into the code path we already trusted.
Fix--aar-mode code runs codeOnlyAarReport and still applies. Live default is code. Tests assert it is not noLlm.
LessonThe graph is a tool. The cited patch is the product. Do not bill a graph the timeout already replaced.

Scar 13 — Boosting a play that never shot

WhatAAR could boost the opening 5v5 at 0 xG. Retrieve locked it. ser-learn-7 retrieveTop never moved.
Fixboost only if playUsage.xgFor > 0. Reject zero-xg-boost and replace with a play that did shoot.
LessonA boost is a claim about xG. Memory writes need the same honesty as the event log.

Scar 14 — Spark burned the night; Glimmer hid the JSON

WhatHosted Spark was a token furnace. Local Glimmer returned empty content (JSON in reasoning_content) and blew 6s thinking until server --reasoning off and a 120-token cap.
FixDefault Muse = local Glimmer. skipNativeStructured. Read reasoning_content. GLIMMER_MAX_TOKENS = 120. Cost table $0.
LessonLocal models are adapters, not drop-in ChatGPT. Prove JSON-in-6s before a series.

Scar 15 — Empty-net at even strength, and protect-lead while trailing

WhatDirty 3-gamer: pull-early at 5v5, 106 shots / 108 offsides. Honest 7-gamer: home retrieve locked protect-lead-1-1-3 from g4 while losing 1–5.
RoottimeRemainingLt 180 is always true on a 20s period. Net-xG ranking does not care that you are trailing.
FixEN-only pull-early. Lead-protect retrieve gate on main (ff23dd5). ser-emp-8: zero skating. Not yet: offsides 0–2 after the gate (g4 77 / g6 63).
LessonShort periods are a microscope. They will also lie if your triggers assume a 20-minute NHL clock.

8 Pitfalls to avoid next time

Don’t LLM every tick. 36,000 × 12 is not a small experiment.
Don’t put a LangGraph on each skater until Head Coach is stable — independence without a shared play is ten hunts, not a team.
Don’t return Send[] from a random node. Conditional edge or Command.goto, list ends, empty list still assembles.
Don’t keep MessagesValue on a match-long thread. Per-epoch thread_id or period 3 is the whole game.
Don’t store 36k JSON frames. Replay is the footage; MP4 is mail.
Don’t Send[] specialists on a 12s live epoch. Head Coach first, or abort freezes default-structure.
Don’t treat AAR timeout as empty ops. Live still has to apply a cited patch.
Don’t treat --aar-mode code as --no-llm. Code applies. --no-llm is the control that must not write books.
Don’t count Shot rows as skill until F1 cannot fire every tick at the same xG. Count distinct chances.
Don’t call a version bump “learning.” Pass = retrieveTop moved and g0→g6 quality vs a --no-llm twin.
Don’t retrieve empty-net families at 5v5. 20s periods make “last three minutes” always true.
Don’t let protect-lead win retrieve while trailing. Gated on main.
Don’t credit Δ xG while offsides explode. ser-emp-8 +0.176 with 77/63 offsides is not better hockey.
Don’t raise timeouts as the fix. Cap tokens. Skip native structured. Attach the abort signal.
Don’t mix lockfiles. This clone uses npm because pnpm died on corepack.
Don’t bind 0.0.0.0 “for a demo.” Loopback is the product.
Don’t name a node the same as a state channel in LangGraph.js.
Don’t treat --no-llm as optional. It is how CI proves the engine without credits.

10 Lessons you can steal

Hybrid agentic systemsDeterministic world + sparse LLM decisions. The world is the unit test.
Cite or discardLong-term memory changes need a pointer into a log you already trust.
Mirror observationsHome + away puck.x ≈ 0 is a one-liner that caught leaks.
Learning is two diffs(a) Did the menu change vs a no-write control? (b) Did the hockey get better? Say so when only (a) is true.
Local models are adaptersReasoning channels, empty content, token caps, server flags. Ping JSON-in-timeout first.
Short experiments lie about timeIf a trigger is “last three minutes,” a 20s period is always the last three minutes.
